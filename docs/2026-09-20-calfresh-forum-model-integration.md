## Pending histories: integrated contract extension

`pipeline/procbench/conditional_case_frames.py` now supports opt-in
`declared-conditional-case-frame/2`. Each observation must declare one of:

- `completed_interval`: finite, nonempty bounds on an observed encounter.
- `pending_right_censored`: positive lower bound, null upper; endpoint had not
  occurred at the stated historical observation time.
- `completed_lower_bound`: endpoint occurred, but only a lower bound on its
  duration was reported. This is distinct from still-pending status even though
  the numeric likelihood factor is the same.

These use V6's existing Student-t(4) log-report interval/survival kernel. No new
duration likelihood, inference architecture, or default prior was introduced.
Version1 remains strict completed-interval-only. All three real v1 fit targets
