# Workflow: an uncertain hypothesis space for the reading layer (handoff to Codex)

2026-09-30. Requested by Alex ("make the hypothesis space uncertain" is the extension he wants next).
Written by Claude; implementation owner Codex. Toy-statute track only.

## Why

The reading layer is Bayesian *given* one hypothesis space: one set of interpretive questions, one set of
validity rules (reading -> lawful designs), one elicited prior. That space is written by one LLM or person.
Round 5 showed how fragile that is: a blind reader recovered 6 of 7 hidden questions, invented one, and
agreed with the author's validity matrix on only 62.5% of cells, mostly because of one meta-rule
(is procedure the statute does not require *unauthorized*, or merely *permitted*?). Earlier real-corpus
work also showed large parse-to-parse variation. We should treat the hypothesis space itself as uncertain
and let the observations weigh the candidates.

## Model

Two sources of variation, kept separate:

1. **Reader disagreement** (property of the text, shared by all towns): hypothesis H_k =
   (questions Q_k, validity matrix V_k over the common design menu, prior pi_k over answers).
2. **Town disagreement** (per town): reading r_t within H_k, as now (population share w, kappa).

    P(H_k | y) ∝ P(H_k) · P(y | H_k)
    P(y | H_k) = Σ_psi P(psi) · exp(log_marginal_ratio(H_k, psi))

`log_marginal_ratio` is the existing Stage-C output. All hypotheses reuse the SAME Stage-B particles, so the
Stage-B normalizer is common and differences of log_marginal_ratio are log Bayes factors between hypotheses.
H is shared across towns (one hypothesis generates all towns), so the mixture is outside the product over
towns: P(y | H_k) = E_theta[ Π_t Σ_r P(r | H_k) Σ_S P(S | r, psi) L_t(S) ] / (Stage-B normalizer).
Do NOT fold all readers into one flat prior over readings; that would let each town pick a different reader.

Answers (lawful-design sets, designs, burden, counterfactuals) are Bayesian-model-averaged over k.

## Observational equivalence (report it, and use it)

The data see a hypothesis only through the distribution it induces over **lawful-design sets** (rows of V)
and, for the risk choice model, the share of readings under which each design is lawful. Two hypotheses that
induce the same distribution over lawful-design sets have identical likelihood for every psi. So:

- Represent each H_k canonically as its induced prior over lawful-design sets (plus residual rho). This is
  Codex's reading-class collapse applied per hypothesis, and it also makes question counts irrelevant.
- Group hypotheses whose canonical forms are equal (tolerance 1e-12). Report the number of distinct classes.
- For the risk model, keep each hypothesis's own reading measure when computing the lawful share (do not
  recompute on collapsed classes; see the speed audit, section 4).

## Step 2 — Code (one module, one runner, tests)

`pipeline/procbench/toy_statute/hypotheses.py`:
- `load_hypotheses(dir, design_ids) -> list[H]` with V, qids, qprobs, reader metadata.
- `canonical(H, rho) -> (patterns, masses)`; `equivalence_classes(Hs)`.
- `run_hypotheses(L, cost, Hs, choice_grid, eps_grid, kappas)` -> per (k, psi): log_marginal_ratio,
  town posterior over lawful-design sets, town_design; uses `readings.stage_c` (with the v2 contraction and
  collapse).
- `bma(results, prior_over_H) -> P(H_k | y)` per psi and marginal over psi (uniform grid prior);
  averaged town lawful-set probabilities P(S lawful in town t) and design posteriors.

Tests (fast, no network):
1. K identical hypotheses -> BMA equals the single-hypothesis result; weights uniform.
2. Two hypotheses differing only in question labels/order but same V and priors -> same canonical form,
   same log marginal.
3. Two hypotheses, one making the observed design unlawful in every reading -> weight shifts to the other,
   by the analytic ratio at small eps.
4. Canonical collapse equals the uncollapsed Stage C to 1e-12 (reuse Codex's fixture).
5. Hypothesis shared across towns: a 2-town fixture where a flat reading pool would give a different
   answer from the correct mixture outside the product.

Runner `runs/toy_statute2_20260929/run_hypotheses_hs001.py`: loads Stage-B particles for a fit dir,
computes L and cost once (cost via the catalog-aware burden, R2 fix), runs all hypotheses, writes
`hs001/{results.json, bma.json}`. Fitter code must not read `truth/`.

## Step 4 — Scoring (evaluator only; may read truth)

Common currency needs no question mapping: the **lawful-design set** per town.
Truth: row of the author's validity matrix at the town's true reading.

1. Lawful-set recovery: per town, mean Brier over designs of P(S lawful) and log score of the true set.
2. Design recovery: log score and MAP accuracy of the true design.
3. Reader ranking: Spearman between P(H_k | y) and each reader's own lawful-set accuracy against truth
   (computed from V_k vs author V at true readings). Also the rank of the oracle in condition (b).
4. Estimands: burden per step, roll-ups, counterfactual (hens only), BMA vs each single reader.
5. Comparators: BMA; best single reader (hindsight, not a method); median single reader; oracle; prior-only
   BMA (hypothesis prior, no data); the tool-less LLM baseline where it answers the same estimand.

Predeclared directions (no thresholds tuned after seeing results): BMA beats the median single reader on
lawful-set log score; P(H_k | y) correlates positively with reader accuracy; in (b) the oracle is in the
top two. Each is reported as holds / fails.

Identification report: number of distinct classes; for each pair of classes, whether any town's data can
separate them (their lawful-set distributions differ on designs with non-negligible Stage-B likelihood).
Expect hypotheses that differ only on questions leaving no trace (fees, clock start) to be inseparable.

## Proposal (optional; Codex decides whether to implement): from text to meaning, for new drafts

Added after discussion with Alex. The text is observed; its *meaning* (H_k: open questions, validity rules)
is latent. The workflow above learns P(H_k | y) from agency behaviour. Two further pieces would make the
text itself do work. Claude's view on each is given; implement either, both or neither, and record the
decision and reason in the plan doc.

**A. Posterior-weighted readers as a forward model for edits (recommended, cheap).**
To score a proposed edit, run the same K readers on the edited text and weight each reader's reading of
the edit by that reader's posterior weight P(H_k | y) from the original statute. Treat a reader's weight as
its reliability on this statute and its agencies, and assume it carries over to small edits. This gives
P(lawful sets | edited text) and hence predicted burden per town for arbitrary wording, instead of a
hand-declared "this edit settles Q2 = yes". It serves the core goal (score drafts) directly and needs no
new likelihood. Declared assumption: reader reliability carries over from original text to edit; test it
on the toy by writing 3–4 edits whose true meaning the author package defines, and scoring the weighted
readers against that truth vs uniform weights and vs the single best-weighted reader.

**B. A text likelihood p(text | H_k) (legislature as speaker). Claude's view: defer.**
It would let the wording discriminate hypotheses that behaviour cannot (questions with no trace: fees,
clock start), via P(H_k | text, y) ∝ P(H_k) · p(text | H_k) · p(y | H_k). Possible forms: RSA over a set of
drafting alternatives per H_k, or LLM log-probability of the actual text given a statement of H_k. Both
are hard to calibrate, and an uncalibrated p(text | H_k) can swamp p(y | H_k). Legislative intent is not
needed for burden prediction; agencies' reading is. If attempted, report results with and without the text
factor, and treat it as a sensitivity, not the headline.
