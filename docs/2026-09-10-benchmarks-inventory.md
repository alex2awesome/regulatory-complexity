# Inventory: benchmarks and datasets for building process models and decision models

Compiled 2026-09-10. Every row was verified by web search or page fetch on that date; a row is included only if it has a citable URL. Sizes marked "~" are approximate; "not verified" means the primary source was not reachable or did not state the figure. Column "gold source" answers: is the reference a human-authored model, an observed event log, or behavioral test cases?

Legend for the notes column: **T→M** = text-to-model with paired gold (the combination this project needs); **collection** = models without paired text; **log gold** = observed behavior, not text.

## Coverage gaps

Based only on what was verified above:

1. **Law/regulation text → process model (BPMN or similar) with public human gold: none.** The closest are BREX (regulatory and administrative documents → rule-flow graphs, 409 docs, expert-annotated, but rules/dependencies rather than a process model, and not statutes), the CoopIS 2025 regulatory-text paper (dataset release not verified), and PAGED (procedural documents, not law). Government BPMN (Swiss eCH, BPI Challenge 2018/2020 logs) exists but is never paired with the statute it implements.
2. **Law text → decision model with public gold: essentially one dataset, not yet verified public.** Graus (2026) has 95 production Dutch permit decision models with test scenarios; NormBench has 2,290 provisions → deontic trees (release not verified); SARA and DeonticBench have Prolog gold but pose an answering task; the NLLP 2025 Catala benchmark has 591 provision → code pairs scored by similarity, not execution. No statute → DMN / decision-table benchmark exists.
3. **Text → DMN outside law is tiny and pre-LLM.** Text2Dec (size unknown), 809 labelled sentences (ESWA 2023), 6 descriptions (RuleML 2023). No LLM-era public text→DMN benchmark was found; DMN-TCK provides execution gold but no text.
4. **Text + process model + event log triples: 20 (ProMoAI, simulated logs) and 1 (CCC19).** All process-mining gold (BPI, PDC) is logs or synthetic generating models, never text.
5. **Rules-as-code test suites are not used as text→code benchmarks.** OpenFisca tests: no benchmark use found. PolicyEngine's PolicyBench uses the engine as oracle to grade LLM *answers*, not generated code or models. Catala tests were judged too scarce to score generated code.
6. **No benchmark anywhere scores a *simplified* or *modified* rule/process against an original for behavioral harm** (the "least-harm simplification" task); the nearest ingredients are DMN-TCK, OpenFisca/PolicyEngine tests, and Graus's functional-equivalence scenarios, all of which compare a candidate to an oracle on fixed cases.
