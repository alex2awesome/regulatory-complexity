# Benchmark 1 gold process models

One file per `(process slug, gold implementer)`: `<slug>__<implementer_slug>.json`, in the
`process_truth` shape defined in `benchmark/synth/DESIGN.md` (extending
`pipeline/schemas/process_model.schema.json`) with `visibility`, `timing`, `fee`, `rework`,
`element_ref` and a verbatim `evidence` span on every activity, plus `timing_gold`, `denial_rate`
where documented, and an explicit `known_gaps` list saying what the source documents do *not*
settle. `gold_tier` is `designed` where the model rests only on designed-tier documents and
`designed+observed` where official or third-party statistics also pin the timing or the outcome
rates. Scores are reported per tier (see `benchmark/realworld/README.md`).

Agents append to the table below; do not rewrite existing rows.
